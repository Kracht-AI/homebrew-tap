# Kracht Homebrew tap

```bash
brew install kracht-ai/tap/kracht
```

`kracht` rents GPU machines and connects to them. See [kracht.ai](https://kracht.ai).

## What is in here

Generated cask metadata and nothing else: a version, the download URLs on
`dl.kracht.ai`, and their SHA256 checksums.

**No source code lives here, and none ever will.** This repository is public because
Homebrew has to read the recipe to install anything — a private tap fails for every
user. The Kracht CLI itself is closed source and proprietary.

Everything under `Casks/` is written by GoReleaser on release. Edits made by hand are
overwritten by the next tag.
